    开发视频源

    用四个 C 符号，把新平台接入 Kivo。

    无需改动宿主源码或播放器 UI。插件只负责链接识别、目录解析、播放地址与可选弹幕，宿主负责影视库、libmpv 播放与遥控导航。

    安装与安全说明

    插件以 .bundle 分发，加载前校验清单、API 版本与二进制 SHA-256
    1. 01

      随包安装或导入本地包

      打开 Kivo「设置 → 插件」，可直接安装随应用提供的官方插件，或导入本地可信的 .bundle 插件包。

    2. 02

      按需登录与添加链接

      需要账号的平台通过官方页面扫码登录；回到「视频源管理」粘贴链接即可预览并入库。

    3. 03

      停用、卸载与内容分级

      停用或卸载不会删除影视库与观看进度；替换新二进制需要重启 Kivo。公开目录仅展示 general 分级插件。

    准备你的插件清单

    新插件包必须在 plugin.json 和最终 Contents/manifest.json 顶层如实声明 contentRating，并在编译签名后写入二进制 SHA-256。

    1. 1. 基于 SDK 1.1.1 打包

      下载 KivoPluginSDK-1.1.1.zip，在 Template 上实现并执行 bash build.sh 生成 .bundle。

    2. 2. 核对 plugin.json 清单 
      {
  "id": "com.yourname.source",
  "name": "平台名称",
  "version": "1.0.0",
  "apiVersion": 1,
  "contentRating": "general",
  "executable": "PluginSource",
  "summary": "一句话说明支持的链接与能力。",
  "capabilities": ["collection", "playback"]
}
    3. 3. 遵守安全边界

      不绕过 DRM、付费或地区限制；错误信息和日志不泄露媒体 URL、Cookie 与请求头。
