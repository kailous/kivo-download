插件 SDK 获取 Kivo

KivoPluginSDK v1.1.1 · API v1 / v2 · macOS 14+

为 Kivo，
接入新的视频源。

插件以进程内 C ABI + UTF-8 JSON 运行，只需输出目录、播放资源、账号与弹幕数据；影视库、遥控导航与 libmpv 播放由 Kivo 统一提供。

快速开始

四条命令，编译出你的第一个 .bundle。

解压 SDK 后复制 Template，修改 plugin.json 与 Swift 源码即可打包并在 Kivo 设置中安装。

复制模板并构建

API v1 · 推荐起点

模板已导出四个必需的 public C 符号，build.sh 会在签名后自动写入二进制 SHA-256 并校验 contentRating。

cp -R Template MyPlugin
cd MyPlugin
# 编辑 plugin.json 与 Sources/PluginSource/TemplateSource.swift
bash build.sh

四个 C 导出入口

零宿主依赖

无需链接宿主模块。v2 内联 HLS 插件导出对应的 _v2 符号，其余所有权与回调规则完全一致。

void *videohub_plugin_create_v1(void);
int32_t videohub_plugin_can_handle_v1(void *inst, const char *link);
void *videohub_plugin_data_store_v1(void *inst);
void videohub_plugin_request_v1(void *inst, const char *op,
    const char *payload_json, void *ctx, videohub_plugin_reply reply);

包内容

只包含开发所需的最小集合。

不含宿主源码、播放器、WebView UI、mpv 或任何第三方平台实现。
